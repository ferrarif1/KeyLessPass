# 20260807 研究目标执行报告

## 总体结论

本轮已把主线从“标准密码学组件的工程组合”收敛为“精确策略空间派生及其
版本化凭据生命周期”。实现、数学说明、实验、形式化模型和论文已经相互
对齐，但查新结论同时限定了可主张的创新：正则语言计数、Rank/Unrank 和
Rank-then-Encipher 都是已有工作，不能将 PSPPD 包装为全新密码学原语。

当前最可辩护的贡献是：把这些已有理论做成一个可执行、可版本化、不会
静默改变旧凭据的企业密码派生与轮换协议，并显式处理策略 epoch、稳定盐、
历史排除、远端不确定结果和恢复代次。这个定位比原稿更可信，但仍需真实
策略语料和真实 adapter 才适合投稿。

## 关键工程修正

- v3 的 `credentialGeneration` 是置换输入，不进入 tweak。
- 同一凭据 lineage 的盐在轮换中保持稳定；策略变化显式增加
  `policyEpoch` 并把 epoch 内 generation 重置为 0。
- 版本 dispatch 仅接受明确支持的 `(derivationVersion, encoderVersion)`
  组合，未知组合失败关闭。
- migration 只创建 pending v3 记录，不自动提交或覆盖 v2 active 记录。
- 最近历史通过旧 CDR 重派生比较；跨不可用 Root-Key generation 时拒绝。
- 网络审批票据绑定 blinded request hash；同 nonce/同请求返回相同节点
  响应，同 nonce/不同请求拒绝。

## 已验证证据

- Rust：78 个测试全部通过；全部 target/feature 的 Clippy `-D warnings`
  通过；格式检查通过。
- TLA+：127 个生成状态、64 个不同状态、深度 13，六项不变量无反例。
- 策略语料：12 个合成策略中 11 个编译，1 个在 25 万状态上限失败关闭。
- 分布：254 输出、每种 10 万样本；Encoder v2 的经验 TVD 为 0.06668，
  均匀 rank/unrank 基线为 0.02056。
- 碰撞：玩具域全 254 generations 中 Encoder v2 观察到 93 个碰撞；双射
  oracle 为 0；真实 v3 后端 2,000 generations 观察到 0。
- 性能：18 位策略完整 v3 派生中位数约 76 微秒、P95 约 171 微秒。
- 恢复支持：10 万对象扫描、1,000 次本地门限释放、全部十种 3-of-5
  重构组合完成。

## 投稿前仍缺少的证据

这些项目没有虚构为已完成：

1. 与 MFDPG 在同一真实企业策略数据集上的直接兼容性和分布对照；
2. 两个真实服务 password-change adapter 及提交后重新认证；
3. 每个网络和持久化边界的系统化崩溃/断线故障注入；
4. Windows、Linux 和 macOS 三平台测量；
5. 部署后的线性化 CAS freshness 服务；
6. 恢复介质小规模可用性实验；
7. 生产级 threshold VOPRF、签名审批、主动刷新和真实 P2P 对抗实验；
8. 一个实现语义与证明完全一致、具有可接受总性边界的有限域置换后端。

因此当前成果适合作为“完整研究原型和投稿稿件第一版”，不应描述为已经
达到生产部署或高概率接收状态。下一轮最能提高接收概率的投入不是继续
润色，而是补真实策略 corpus、MFDPG 同输入复现、两个真实 adapter 和
故障注入。
