# 安全说明

English: [SECURITY.md](SECURITY.md)

- 随机数来自操作系统 CSPRNG。
- 助记短语不落盘。
- 目标系统明文密码不落盘。
- 不存在加密服务密码 vault。
- CDR 和因子包带完整性标签。
- 因子包和恢复元数据带 schema/version 字段。
- 新初始化会保存受保护的助记短语校验器；校验器不是恢复 secret。
- 派生密码只短暂显示或复制，Flutter 默认 30 秒后清剪贴板。
- 日志不得包含助记短语、主密钥、因子、U 盘 payload 明文或派生密码。
- 客户端本地回滚检测只覆盖本机/U 盘元数据和 MAC；如果攻击者协调回滚所有本地副本，需要外部可信状态或追加式审计。

## 2-of-3 恢复边界

- `Kmaster` 是初始化时随机生成的 256-bit root secret。
- `Kmaster` 不以明文保存到本机因子包或 U 盘因子包。
- `Kmaster` 落盘时只存在于 `W_MC`、`W_MU`、`W_CU` 成对 wrapper 密文中。
- 助记短语 + 本机：通过 `W_MC` 恢复。
- 助记短语 + U 盘：通过 `W_MU` 恢复。
- 本机 + U 盘：通过 `W_CU` 恢复，并可在不知道旧助记短语时重置助记短语。
- 日常派生使用助记短语 + 本机，U 盘可以离线保存。
- 单个因子不能恢复 `Kmaster`。
- U 盘是普通可复制存储；复制 U 盘包等于复制 U 盘因子，但还需要助记短语或匹配本机因子才能恢复。

## V2 包说明

- 本机包保存本机元数据、助记短语校验器、`W_MC` 和可选 `W_CU`，不保存 `usbSecret`。
- U 盘包保存 U 盘因子材料、`W_MU` 和 `W_CU`，不保存 `deviceSecret`。
- V2 `encryptedPayload` 是历史字段名，现在是 base64 编码因子 payload，不包含明文 `Kmaster`。
