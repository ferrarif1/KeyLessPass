# Mechanistic controls

These controls explain distribution and collision mechanisms. They are not published competing schemes and do not appear in the main SOTA comparison.

- `uniform-rank-unrank-oracle` checks the exact rank/unrank intervals against uniform integer ranks.
- `equalViableBranchWalk` is an analytic counterexample showing that locally equal branch probabilities need not be uniform over complete accepted words.
- `withReplacementOccupancy` reports the standard expected unique/repeated counts for independent uniform draws.

The separately pinned MFDPG preprint-artifact probe is stored under `experiments/mfdpg/` and is also excluded from the published-baseline table.
